# SayTrace 0.3.0 — macOS Apple Silicon

SayTrace 0.3.0 adds native support for Apple Silicon Macs running macOS 15 or
newer while preserving the existing Windows 11 x64 path.

## Highlights

- Speech recognition runs locally through MLX/Metal; diarization and speaker
  embeddings use PyTorch MPS when available and otherwise fall back to CPU.
- Microphone and system audio use a coordinated ScreenCaptureKit capture path.
- Hardware-adaptive resident model caching, recording-time prewarming, bounded
  media parallelism, and lower-frequency renderer updates improve startup,
  transcription, finalization, and transcript navigation.
- A warm transcription benchmark on an 11.275-second recording improved from
  10.872 seconds to 4.709 seconds (2.31x) with identical 10-word output and one
  model load.

## Verification

- 35 frontend tests passed.
- 76 Python worker tests passed, together with formatting, lint, and strict type
  checks.
- 114 Rust tests passed; two interactive tests were intentionally ignored.
- An optimized, signed arm64 development bundle built and launched successfully.

## Models and privacy

No model weights are bundled in the app or DMG. Required weights remain
explicit, revision-pinned, hash-verified first-run downloads. After setup,
transcription, diarization, speaker matching, and transcript data remain local;
the worker runs offline and exposes no listening network port. Transcript
questions use only an installed Ollama model on the loopback interface.

## Distribution status

**Not yet an official macOS release.** A local candidate signed with Apple
Development remains unnotarized and must not be published as stable. The
current release Mac has no Developer ID Application identity or configured
Apple `notarytool` Keychain profile, so official preparation is blocked. Those
credentials are external release prerequisites, not something this source tree
can supply.

After official preparation, the exact signed, notarized, and stapled DMG under
`artifacts/macos/prepared/v0.3.0` must pass every check in its generated physical
acceptance template on a clean Apple Silicon Mac. The completed record must bind
the tested DMG's exact name, size, and SHA-256 digest. Only
`script/finalize_macos_release.sh` may promote those accepted bytes to
`artifacts/macos/v0.3.0`; only that finalized directory is publishable.

See the [macOS release workflow](../macos.md#macos-release-workflow) for the
candidate, preparation, physical-acceptance, and finalization commands. Until
all of those gates pass, any macOS build is a preview rather than an official
SayTrace 0.3.0 release.
